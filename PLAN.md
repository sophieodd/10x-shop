# 10X Shop — Plan

## Goal
Build a responsive React storefront with a product catalog, product details, simulated login, cart and checkout.

## Stack
React, TypeScript, Tailwind CSS v4, Vite, React Router and DummyJSON.

## CORE milestones
1. Set up Vite, TypeScript, Tailwind, and Git. (Done)
2. Add the app layout, routes, and required data types.
3. Build simulated login and the checkout access guard.
4. Load and display the catalog and product details from DummyJSON.
5. Build shared cart state and the cart page.
6. Add checkout validation and local order confirmation.
7. Check responsive layouts, document the project, and deploy.

## Scope
Complete CORE requirements first. Login and checkout are local simulations; no real authentication or payment processing is included.
